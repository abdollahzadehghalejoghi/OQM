📢 Dual Notification Mode

When Admin Chat ID is configured, notifications are sent to both the user/group AND the admin simultaneously. This ensures the admin receives all events while users also get their own notifications.

💡 Tip: Notifications will be sent when:

  • User reaches 80% of quota (warning)
  • User quota exceeded (blocked)
  • System events (daemon start/stop, resets)
